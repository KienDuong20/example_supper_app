# PLAN — example_supper_app (minimal Super App + Mini App)

Goal: a **small, runnable example** that shows the *architecture* of the MyMobiFone Super App
(`mobile-superapp-react`) + mini apps (`miniapps`) — **app layer only, no backend**.
Features are reduced to the minimum needed to show each architectural concept once.

---


## 2. Streamlined scope (what is IN / OUT)

**Host — IN**
- 1 Home screen: list of mini app tiles (from runtime manifest)
- 1 MiniAppScreen: kill-switch screen, "update required" screen, WebView
- Bridge with **3 calls only**: `callApi`, `requestOtp`, `confirm` (stand-in for biometric)
- Capability policy (allowlist, real default-deny)
- Mock API: 2 endpoints (`GET /packages`, `POST /topup`)
- Fake session: a constant msisdn (no login screen)

**Host — OUT** (exists in prod, skipped here)
login/OTP login, tabs, deep links, push, CDP analytics, legacy catalog, i18n,
native fallback screens, biometrics library, version tracking in 4 places.

**Mini apps — only 2**
| Mini app | Shows | Capabilities |
|---|---|---|
| `miniapp-hello` | read API via bridge (list packages) + a **denied** call (tries topup) | `[]` |
| `miniapp-topup` | secure write: confirm → OTP → `POST /topup` | `payment.create`, `otp.request`, `confirm` |

**Mini apps — OUT**: shared component library, hero, theme system, ES5 constraint, manifests per 17 apps.

## 4. Contracts

**manifest.json (per mini app) → runtime.json entry**
```json
{ "id": "miniapp-topup", "name": "Top-up", "version": "1.0.0",
  "enabled": true, "minHostVersion": "1.0.0",
  "capabilities": ["payment.create", "otp.request", "confirm"],
  "bundleUrl": "<CDN>/miniapp-topup/1.0.0/index.html" }
```

**Bridge message (mini app → host)**
```json
{ "type": "callApi" | "requestOtp" | "confirm", "requestId": "r123", "payload": {...} }
```
**Reply (host → mini app)**: `window.__bridge._resolve("r123", ok, data)` via `injectJavaScript`.

**Capability policy (allowlist)**
```
requestOtp           → otp.request
confirm              → confirm
callApi GET  /packages → (public)
callApi POST /topup    → payment.create
anything else          → DENIED
```

## 5. Flows the example demonstrates

1. **Launch** — Home shows fallback list instantly → fetch `runtime.json` → merge → re-fetch on app foreground.
2. **Open mini app** — tap tile → `enabled?` (else "Tạm khoá") → `minHostVersion` ok? (else "Cần cập nhật") → WebView loads `bundleUrl?v=<version>` with bridge injected.
3. **Read call** — hello: `MiniSDK.api("GET","/packages")` → policy ✔ → mockApi → list rendered.
4. **Denied call** — hello: `MiniSDK.api("POST","/topup")` → policy ✘ → promise rejects "missing capability payment.create".
5. **Secure write** — topup: `confirm()` (native Alert) → `requestOtp()` (native modal, OTP `123456`) → `POST /topup` ✔.
6. **Hot deploy** — edit `miniapp-hello/app.js`, bump version in its manifest, `node tools/build.js` → foreground the app → new version loads, no reinstall.
7. **Kill-switch / force update** — set `enabled:false` or `minHostVersion:"9.0.0"` → rebuild → app reacts.

---

## 6. Deliberate improvements vs production (marked `// NOTE:` in code)

- Policy is a true **allowlist** (prod: deny-list; unmatched paths allowed).
- WebView navigation **pinned to the CDN origin** (prod: bridge injected into any page).
- Capabilities come **only from runtime manifest** (prod: union with local hardcoded list).
- Single source of truth: `manifest.json` → generated `runtime.json`.

## 7. Steps

| # | Step | Done when |
|---|---|---|
| 1 | Scaffold RN CLI app in `host/` (`npx @react-native-community/cli init … --version 0.79.2`), add `react-native-webview`, `pod install` | blank app runs on iOS simulator + Android emulator |
| 2 | `tools/build.js` + `_sdk` + `_template` + `miniapp-hello` | `dist/` contains bundle + runtime.json |
| 3 | `RuntimeContext` + `HomeScreen` | tiles come from runtime.json |
| 4 | `MiniAppScreen` + `MiniAppHost` + bridge + mockApi | hello lists packages |
| 5 | `capabilityPolicy` + `miniapp-topup` + `OtpModal` | flows 4 & 5 work |
| 6 | README: concept + run guide + demo script for flows 1–7 | someone new can follow it |

**Run (target)**
```bash
node tools/build.js && node tools/cdn.js        # terminal 1: build + "CDN" (port 8080)
cd host && npm start                             # terminal 2: Metro bundler
cd host && npx react-native run-ios              # terminal 3 (or run-android)
```
First time only: `cd host && npm install && cd ios && pod install` (system `pod`, no `bundle exec` — same rule as prod).
Android emulator reaches the CDN at `10.0.2.2:8080`; iOS simulator at `localhost:8080` (handled in `config.js`).

## 8. Decisions taken
- Host: **React Native CLI (bare)**, RN 0.79.2 / React 19 — same stack as production `mobile-superapp-react`, no Expo.
- Mini apps: **modern JS**, no framework, no bundler.
- No backend: mock API inside host, static server as CDN.
